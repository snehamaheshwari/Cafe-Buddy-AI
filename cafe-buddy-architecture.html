② Presentation Layer  —  React 18  +  TypeScript 5  +  Vite 5
🔐 Auth & Access Control
  • AuthContext — session state + /api/auth/me polling on every tab focus
  • PermissionRoute — RBAC gate wrapping every page route
  • apiFetch.ts — injects X-Username + X-Role on every request
  • 3 system roles: admin / sub_admin / viewer + custom roles
  • Session stored in localStorage as {username, role, permissions[]}

  • WhatsApp Alerts · Role Mgmt · Audit Log
📦 UI Stack & API Client
  • React Router 6 — SPA routing with nested guards

  • Tailwind CSS 3 — utility-first styling
  • Lucide React — icon set
  • api.ts — fully typed REST client for all endpoints

  • Template download via dynamic <a> element
